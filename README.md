# Billions Timeline

An interactive web-based timeline that chronicles the history of the Billions Network from its Discord community launch to the present day.

## Description

This project presents the Billions Network journey through an engaging Twitter-like interface. Users can navigate through 193+ timeline events, featuring announcements, community milestones, media content (images and videos), and key developments in the project's evolution.

## Features

- **Interactive Timeline**: Navigate through chronological events with intuitive controls
- **Media Support**: View images, videos, and embedded content within timeline posts
- **Auto-Play Mode**: Automatic progression through the timeline with customizable skip intervals
- **Audio Experience**: Background music and sound effects enhance the journey
- **Responsive Design**: Optimized for various screen sizes
- **Progress Tracking**: Visual progress bar and dot timeline for easy navigation
- **Event Summaries**: Highlight important community events and announcements

## Technologies Used

- **HTML5**: Structure and semantic markup
- **CSS3**: Styling with modern effects and animations
- **Vanilla JavaScript**: Interactive functionality and media handling

## Installation & Usage

1. Clone or download the repository
2. Open `index.html` in your web browser
3. Click "ENTER THE JOURNEY" to begin
4. Use navigation buttons or auto-play to explore the timeline

## Controls

- **Navigation**: Previous/Next buttons or click on dots in the timeline
- **Auto Mode**: Toggle automatic progression through events
- **Skip**: Jump forward by a specified number of events
- **Mute**: Toggle background music on/off
- **Media**: Click on images/videos to view in full screen overlay
